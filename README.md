# Colony Park Football

Gully football in a 3D colony park, in the browser. 3 vs 3 against Rohan's team, with gully tricks (panna, chakma, palti, tappe, angootha shot), Hinglish banter, rain, power cuts, the balcony aunty, and Mummy calling you home when time runs out.

Play: https://gullyfootball.ritikeshvali.com

## Controls

- Phone: joystick to move, hold KICK and let go, PASS, TRICK (tap or swipe), Badlo to switch kids.
- Keyboard: WASD move, Shift run, Space kick, R pass, X switch, E trick, Q flick, F drag-back, Esc pause.

## Tech

One `index.html`, Three.js r128 from cdnjs, all sounds synthesised with Web Audio. No build step.
